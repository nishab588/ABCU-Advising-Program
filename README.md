# DSA-Analysis-and-Design

1. What was the problem you were solving in the projects for this course?

In this course, the primary problem I was solving was how to efficiently store, organize, and retrieve course information for ABCU’s advising program using appropriate data structures. The goal was to read course data from a file, validate it, store it in a structured way, and allow users to search and print course information efficiently. The challenge was not just making the program work, but selecting and implementing the most appropriate data structure to meet performance and functional requirements.

3. How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by carefully analyzing the advantages and disadvantages of vectors, hash tables, and binary search trees. Understanding data structures was critical because each structure impacts performance differently, especially in terms of searching, sorting, and memory usage. Through Big O analysis, I was able to compare the efficiency of each approach and determine that a binary search tree provided the best balance between maintaining sorted order and offering efficient search performance. This process reinforced how important it is to understand not just how to code something, but why a particular data structure is the best fit for a given problem.

5. How has your work on this project expanded your approach to designing software and developing programs?

I tend to avoid planning because I struggle with flowcharts and pseudocode. Completing this assignment required me to write pseudocode each week leading up to it, and that consistent practice forced me to slow down and think through the logic before writing code. As a result, writing the actual program became much easier and more organized. I gained a lot more confidence in my ability to write effective pseudocode, which ultimately improved my coding efficiency and overall problem-solving process.


6. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

Writing pseudocode has always been a struggle point for me, but the amount of structured planning required in this course helped me grow significantly in that area. By investing more time in the planning stage, I found that my final code was cleaner, more organized, and easier to debug. This experience showed me that thoughtful design and preparation are essential steps in developing software that is maintainable, readable, and adaptable over time.
